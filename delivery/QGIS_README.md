# QGIS客户交付文件

下载 `Wuhan_Study_QGIS.qgz`，使用 **QGIS 3.40 LTR或更新版本**双击打开即可；已在3.40.6验证。

这是自包含单文件：GIS数据、配色、字段别名、地图主题和打印布局均内嵌，不需要额外数据目录或联网底图。共有86个图层/表、14个地图主题及14个A3打印布局。默认蓝绿整体1km核密度；可通过图层面板的地图主题菜单切换。

- 布局：项目→布局，选择对应图件后导出。
- 数据：右键图层→打开属性表或导出，原始数值与完整字段保留。
- 查看完整规则网格时，可临时关闭“范围外白色遮罩”；该遮罩只影响显示，不改变数据。
- 编辑前建议另存一份QGZ；修改内嵌数据后也需保存工程。

范围为用户研究边界，面积3255.59km²（投影平面），蓝绿整体55.5090%。数据年份待补充；分类精度未独立验证；标准最新现行性未在线核实；坐标转换采用默认近似。绿色含耕地，蓝绿整体含独立湿地。核密度单位ha/km²，网格占比单位%，KDE本身没有p/q显著性。
