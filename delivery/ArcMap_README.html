武汉蓝绿空间｜ArcMap 10.5整合包

本包包含当前用户研究范围的全部GIS数据、完整属性和43个已配色地图视图。源数值数据与显示图层分开保存，原始值不因配色而改变。

直接导入使用

  1. 完整解压整个文件夹。
  2. 在ArcMap 10.5中点击“添加数据”：矢量和统计字段位于 Data/Wuhan_Study.gdb；已配色地图位于 Views；原始数值栅格位于 Data。

交付方先生成MXD，客户以后直接双击打开

  1. 在您已安装ArcMap 10.5的电脑上双击 OPEN_ARCMAP.cmd。
  2. 程序会寻找ArcGIS自带Python和真实空白MXD模板。找不到时按窗口提示选择；空白模板可在ArcMap中“新建→另存为Blank_Template.mxd”。无需编辑代码。
  3. 本机将生成真实 Wuhan_Study.mxd 和 Native_Layers/*.lyr，设置相对路径、字段别名和默认地图，并重新打开检查断链。
  4. 本机10.5还会尝试生成单文件Wuhan_Study.mpk。若生成成功，可把该MPK单文件交给客户，由ArcMap解包打开；打包失败会保留错误记录，不影响MXD。生成MXD成功后，也可将整个文件夹交给客户；客户双击 Wuhan_Study.mxd 即可。不要只发送MXD或移动Data/Views子目录。

本包当前不含云端生成的MXD或LYR：云端没有ArcGIS，不能生成或验证MXD/LYR/MPK原生文件。Windows入口须在真实ArcMap环境中运行，云端未执行。

地图切换与数值查询

默认显示蓝绿整体1km核密度，范围轮廓与范围外留白应保持开启。切换主题时关闭当前显示层，再勾选所需分类、分布、核密度、LISA或Gi*显示层。RGB显示层只负责配色；查询/计算密度请选“原始数值”浮点栅格，空间统计请读取GDB网格字段。主核密度单位ha/km²；网格面积占比单位%；两者不同。

范围和方法

研究范围为用户边界，面积3255.59km²（EPSG:32649投影平面）；蓝绿整体55.5090%。绿色含耕地，蓝绿整体含独立湿地。数据年份待补充；15m源像元不是分类精度。边界行政/规划属性、分类标准最新现行性未独立核实；CGCS2000到WGS84为默认近似转换，无控制点精度验证。KDE为描述性集聚，不等于显著热点或生态质量。

详细方法、字段字典、类别对应、验证记录及参考图件见Documents；CSV明细见Tables。下载校验清单用于初始化前的完整性检查；初始化会新建MXD/LYR并设置GDB别名。
