## 标准与限制

按已知正式文件《国土空间调查、规划、用途管制用地用海分类指南》（自然资发〔2023〕234号）对应整理；**最新现行性尚未在线核实**，官方门户访问被网络策略403拒绝。耕地/林地/草地/湿地只对应一级；建设、裸地及水体语义不能唯一确认处不赋唯一STD_CODE。无独立验证样本，不能给出分类精度；15m不等于分类准确率达到15m。

已重读GeoTIFF、Shapefile及GeoPackage；所有地图PNG验证、PDF解析渲染完成。ArcMap10.5脚本未在云端运行，未声称通过ArcMap打开验证。

## 下载后复现

解压完整成果包，保留目录结构，执行：

```bash
bash scripts/run.sh
```

Python3.12及开源依赖版本见scripts/requirements.txt和environment_versions.json。当前云环境复用/workspace/wuhan_python；其他机器建立本地.venv并安装固定版本。需能下载依赖；不依赖ArcGIS或付费API。参数在config/analysis.json。输入影像已随包保留。全过程约数分钟至十余分钟，视机器和制图速度而定。

主图请选择文件名含1000m的密度、LISA、热点图；500m/2000m为敏感性，非按显著单元更多选定。完整网格full与裁剪网格clip、字段字典及完整CSV可通过GRID_ID连接。
