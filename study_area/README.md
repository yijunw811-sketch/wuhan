500m/1km/2km及边缘比例0/0.25/0.5均重新计算，不沿用整幅影像统计。所有实际情景均无孤立单元。解析正态p与置换p分列；极小解析p可能下溢为0，推断采用置换p。精确推断公式、尾部和种子控制见methods/statistical_inference.md及配置/脚本。

## 精确边界像元与网格面积

先对边界线附近像元分块求真实像元—多边形交集；完整内侧像元面积225m²，边缘以交集面积计入。共30358个部分相交像元，未把整幅像元逐一矢量化。`exact_fraction.npz`存双精度面积比例用于计算，`study_fraction.tif`是ArcGIS用float32覆盖比例。分类/二值栅格保留所有正面积相交像元的原类别，范围外为NoData；这不表示边界像元全225m²都在区内，精确面积须结合比例或表格。`touched_pixels`为相交像元计数，`equivalent_full_pixels`为面积/225，不能混用。

网格沿原影像左下角固定原点。bulk计算使用像元—网格重叠矩阵；对同时被研究边界和网格边界切开的像元，再以真实几何交集修正各格面积，不用整体比例简单分摊。规则完整网格保留全部GRID_ID，clip只保留正面积相交几何。有效覆盖=有效分类面积/研究范围交集面积；边缘比例=交集面积/完整网格面积。主统计纳入覆盖≥95%、边缘比例≥25%，真实零与OUTSIDE/NULL/-1分开。最大全格面积核对误差约1.2e-7 m²，全域差小于0.01m²容差。

## 真正核密度（主密度图）

不是从旧密度图裁个形状：使用新的边界内像元相交面积作为质量重新计算。每源像元质量=其研究范围内面积/10000公顷，分块卷积四次核 K_h(d)=3/(πh²)×(1-d²/h²)²（d<h，否则0）。h、d以km计时密度单位ha/km²。核在15m源网格离散求积并归一化，主搜索半径1000m，补充500m、2000m。核像元中心代表带面积权重的质量，属于有限像元近似，不声称为连续面精确KDE积分。

边缘曝光E以研究范围的部分像元覆盖比例卷积计算，主图λ_edge=λ_raw/E。范围外既不计目标面积，也不当作有效的非蓝绿；同时提供raw、曝光E与90m实际研究覆盖比例。核计算保留15m源质量，输出为按研究面积权重聚合的6×6（90m）格均值。部分90m格的积分/均值须用study_coverage_90m.tif；不能整格计面积。RGB着色GeoTIFF仅供ArcMap显示，定量计算用浮点kde_*.tif。

核函数/halo分块与整幅卷积、小例FFT与直接卷积、恒定场边缘修正、原始截断积分、90m加权聚合和蓝+绿+湿地=蓝绿整体均验证通过。校正后的全域积分不要求等于原始面积。KDE为描述性集聚，不具有p/q值；保留原网格Moran/LISA/Gi*独立含义。

## 空间格局

研究范围内蓝色核密度高值主要沿河流类水体及部分较大湖泊类斑块形成带状/团块集聚。绿色与蓝绿整体在范围南部、北部及部分外围较高，中部建设类集中区域较低，局部水体廊道则提高蓝绿整体占比。500m保留更多细节，2km更平滑；主半径预先取1km。高密度或集聚不等于生态质量、生态服务、重要性或发展潜力。

## ArcGIS 10.5

分析包内`data/wuhan_results.gdb`为GDAL实际写出的真实文件地理数据库，目标ALL，使用32位OID/整数、double和text。网格、裁剪几何、NULL、完整数值和代码前导零均回读核验。Shapefile短字段≤10字符且显式映射，`.cpg`为UTF-8；完整CSV与字段字典可按GRID_ID连接。

GeoTIFF为常规LZW编码，分类整数、密度float32；核密度包含RGB着色显示栅格。云端无ArcGIS，未通过ArcMap打开验证，也未生成/伪造MXD。分析包`create_mxd_arcmap105.py`可在本机ArcMap10.5/Python2.7中加载真实GDB和栅格、设置别名、保存并重开检查MXD；若两个包并排解压，还会加载新的核密度RGB。可使用CURRENT（ArcMap内）或真实空白MXD模板。

ArcMap Python窗口示例：
```python
import sys; sys.path.insert(0, r'D:\wuhan_study')
import create_mxd_arcmap105 as w
```

## 标准与限制

按已知《国土空间调查、规划、用途管制用地用海分类指南》（自然资发〔2023〕234号）对应整理；官方访问受限，执行时最新现行性尚未在线核实。水体、建设和裸地不能唯一对应代码处仍留空，不虚构用途细分；林草不改称公园绿地。原类别与规范/研究显示名称见class_crosswalk.csv。输入分类误差、未知年份、投影平面面积与边界出处限制均仍然存在。

坐标转换说明：PROJ在CGCS2000到WGS84之间使用默认Ballpark近似，未提供高精度转换参数/控制点，操作精度标记为未知。数值面积守恒不代表边界配准达到同样精度。所有面积和核搜索距离均在原影像UTM投影平面计算。两版占比差异来自分析范围改变，不代表时间变化或生态退化。
